# Provider investigation — 2026-11-04

Official sources checked before provider implementation:

- [Gemini Additional Terms](https://ai.google.dev/gemini-api/terms), effective March 23, 2026: users must be adults, and API clients directed towards or likely accessed by under-18s are prohibited. This restriction applies to the actual application, not merely the age of today's testers. Free service content may be reviewed by humans and used to improve Google products. Do not submit personal, sensitive or confidential material. EEA/Switzerland/UK user-facing clients have paid-service restrictions. Regional eligibility must be checked for the actual deployment.
- [Models](https://ai.google.dev/gemini-api/docs/models) and [Gemini 3.5 Flash-Lite](https://aistudio.google.com/docs/models/gemini-3.5-flash-lite): verified model ID `gemini-3.5-flash-lite`, PDF input and structured-output capability. This is configurable, not copied from an old example. Existing 2.5 examples should not be assumed suitable for new projects.
- [Pricing](https://ai.google.dev/gemini-api/docs/pricing): the verified model's Standard tier lists free input/output under free quotas. Eligibility/quota availability is account-dependent. A model-metadata response cannot establish that a key is unbilled.
- [Document processing](https://ai.google.dev/gemini-api/docs/document-processing): native visual PDF understanding, up to 50 MB or 1,000 pages. This plugin deliberately caps PDFs at 10 MB and defaults to 100 pages. It rejects larger sources instead of truncating; native input supports readable scans, but poor scans can fail. Poppler checks PDF structure/encryption/pages; the model reports semantic readability. There is no independent OCR quality scoring.
- [GenerateContent REST reference](https://ai.google.dev/api/generate-content) and [structured outputs](https://ai.google.dev/gemini-api/docs/structured-output): server-side REST adapter uses `/v1beta/models/{model}:generateContent`, `x-goog-api-key`, `systemInstruction`, inline PDF data, JSON response MIME type and a response schema. The current docs also promote the newer Interactions API; this implementation retains the documented GenerateContent route. Live compatibility remains to be exercised with an eligible key.

The model receives the entire PDF plus teacher settings. It has no tools, browsing or code-execution capability in this adapter. Source instructions are explicitly distrusted. Output is locally validated and displayed only via escaped template variables. Prompt injection cannot execute scripts, but semantic misinformation and incorrectly placed answers still require teacher review. No fabricated page citation fields are requested; provenance uses source/generated/mixed labels and needs teacher verification.

Provider boundary: `classes/local/provider.php`; implementation `gemini.php`; orchestration `jobs.php`. A replacement must preserve structured validation, request caps, safe failures, and server-side credentials. It must also have terms/data processing appropriate for the intended learners. There are no student AI request endpoints in this release.

Decision: ship the real adapter **disabled**, continue all credential-independent work, and leave actual provider eligibility and live generation unverified. Do not treat an adult-only test toggle as permission to run Gemini inside a child-directed application.
